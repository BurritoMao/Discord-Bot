# Discord-Bot
This project is to gage how well the idea of having an AI chatbot companion. However, due to library constraints, the ability to verbally talk to the Agent is unavailable. This Agent is trained on Angel Dust from Hazbin Hotel.

# Run App
Discord setup:
You can find how to set up your discord account / bot through this link: https://youtu.be/YD_N6Ffoojw
The most important thing is to set up a .env and input your bot token.

Environment Setup:
Run the requirements.txt
You will need three terminals, one for main.py in discord, qwen, and main_pipeline.

How to use:
First follow the youtube video on the installation of adding a discord bot onto your server. Next, run !talk along with your message.
